# 歇会儿 · 一个住在屏幕下角的小动物

> 你坐久了，它会自己冒出来提醒你起来走走。你不管它，它就一直赖在那儿不走。

一个 macOS 菜单栏久坐提醒工具。和普通定时器不同的是：**提醒你的是只会动的动物**——它打哈欠、从椅子上下来伸懒腰、捶两拳，然后摊回椅子上看着你。它可以被戳、会躲、会盯着你的鼠标看。

## 它和别的久坐提醒有什么不一样

**1. 判断依据是「你真的在不在」，不是「时间到了没有」**

用系统空闲时长（距上次键鼠操作多久）倒推专注时长，再叠加熄屏、锁屏这两条硬信号判断你在不在。你确实离开了，计时才归零——不需要你点「我去休息了」，也不会在你刚回来的时候冲你喊。

「没碰键鼠」和「人走了」不是一回事。判定按「证据」分层，**不由时长决定人还在不在**：

| 信号 | 判定 | 计时 | 弹窗 |
|---|---|---|---|
| 熄屏 / 锁屏**持续 ≥ 30 秒** | 确凿离开 | 归零 | — |
| 熄屏 / 锁屏不到 30 秒就回来 | 没走成（误触、屏幕眨一下） | 不动，进度保留 | 正常 |
| 摄像头 / 麦克风被占用 | 在开会 | 照常累加 | 推迟到会后补发 |
| 手停超过 5 分钟 | 静默：可能在思考、看视频、线下开会 | **照常累加** | 照弹，但不升级、不追鼠标 |
| 手停超过 30 分钟 | 长静默：可能真的不在 | **照常累加** | 先不弹，手一回来立刻补 |
| 其余 | 在位 | 累加 | 正常 |

四条反直觉的地方：

- **手停了照样计时。** 没碰键鼠不等于离开——跟旁边人说句话、读文档停下来想、开会听人讲，人都在座位上。停多久都不该冻结，冻结等于把这些时间整段漏记。
- **开会不弹窗，但继续计时。** 摄像头/麦克风被占用时人就在座位上，而一小时起的会把「冻结」变成「整段漏记」——最该提醒的场景反而最安静。所以照常计时，只把弹窗推迟到会后。
- **静默只是克制，不是停止。** 手停超过 5 分钟，提醒照弹，只是不再升级为强提醒、不追着你的鼠标跑——免得你看视频时被追。
- **长静默只是先不弹，不是清零。** 手停半小时以上，累计仍然一秒不落地记着，只是暂时不出卡片（弹了大概也没人应）。手一回到键鼠上，欠下那条立刻补出来。**只有熄屏和锁屏有权删数据**——看一集 50 分钟的剧，数字一直在涨。

屏幕为什么能当证据：它比任何时长阈值都准。系统按你设的熄屏时间（本机 10 分钟）判定人走没走，我们直接借用这个结论——屏幕亮着，人就还在。

早期版本只有一档（1 分钟不动就清零），读一篇长文档的功夫，坐了两小时也会被抹掉——工具漏记的恰好是它最该管的那种久坐。

判定口径故意从紧：**坐够软提醒阈值之后才离开**才算一次真正的休息。随手离开一分钟就想打卡？不算。

**2. 提醒强度是分级的，动物性格也跟着分级**

| 阶段 | 触发 | 弹窗行为 | 动物行为 |
|---|---|---|---|
| 软提醒 | 专注达 `focusMinutes` | 出现在屏幕右下角，白卡片，蓝色按钮 | 克制。被戳抖一下就好 |
| 升级 | 弹出后 `escalateSeconds` 秒无响应 | 卡片转暖色，标题变橙，按钮变橙 | 开始沿屏幕下缘左右游走 |
| 强提醒 | 专注达 `strongMinutes` 仍未响应 | 窗口层级提到 `.screenSaver`，播放提示音 | **贴着你的鼠标跑**，挡在你正在点的位置旁边——但不会盖住你点的地方 |

「越来越烦」本身就是提醒强度的表达。不做全屏遮盖（那样会打断你），也不做静音轮播。

**3. 会开会就闭嘴**

摄像头或麦克风被占用时判定为在开会，不弹窗；会议一结束，立刻把欠下的那次提醒补上。不会因为你开了两小时会就一直沉默到下班。

**4. 有一点点养成的意思**

连续坚持会解锁新的动物形象，第 30 天进入「老友模式」——文案从催促换成熟人语气（「又到 60 分钟啦」），而不是继续加感叹号。

## 安装

### 方式一：下载 dmg（只想用，不想编译）

1. 到 **Releases** 页面下载最新的 `歇会儿-<版本>.dmg`
2. 双击打开，把「歇会儿」拖进「应用程序」
3. **首次打开需要右键 → 打开**——这个 app 没有 Apple 开发者签名，双击会被 Gatekeeper 拦下
4. 首次运行会弹出三屏引导，菜单栏出现 `🚶 0m`

> 右键打开也失败的话：`xattr -dr com.apple.quarantine /Applications/歇会儿.app`
> 这条只是清掉「从网络下载」的隔离标记，不解压、不改内容。不放心就自己编译（方式二）。

### 方式二：自己编译（约 10 秒）

只需要 **Xcode Command Line Tools**，不需要完整 Xcode。

```bash
# 1. 装命令行工具（已装过可跳过）
xcode-select --install

# 2. 编译
git clone <本仓库地址> && cd <仓库目录>
./build.sh

# 3. 跑起来
open 歇会儿.app

# 想打成可分发的 dmg（可选）
./package.sh
```

`build.sh` 做三件事：`swiftc` 编译 15 个 Swift 文件 → 组装 `.app` bundle 并拷入素材 → 本地临时签名（`codesign -s -`）。

环境验证过的版本：**macOS 14 / Swift 6.0.3 / arm64**。理论上 macOS 13+ 都能跑（Info.plist 里 `LSMinimumSystemVersion` 是 13.0）。

### 菜单栏

```

├─ 已连续专注 12 分钟（软 60 / 强 90）
├─ 今日坐 4 小时 20 分 · 已提醒 1 / 8 次
├─ 连续坚持 3 天 · 再 2 天解锁毛绒橘猫
├──────────────────────
├─ 立即提醒我一次        ⌘T     ← 手动预览，不占今天的提醒名额
├─ 预览强提醒            ⌘S
├─ 重置计时              ⌘R
├──────────────────────
├─ 暂停 1 小时           ⌘P
├─ 设置…                 ⌘,
├─ 重新看一遍引导
├─ 解锁全部形象（调试）
├─ 模拟打卡 +1 天（调试）
├──────────────────────
└─ 退出歇会儿            ⌘Q
```

### 卡片上的两个按钮

- **我去走走了** — 清零计时并打卡（只有坐够软提醒阈值才算，防止用这个按钮刷天数）
- **再等 N 分钟** — 顺延 `snoozeMinutes` 分钟

### 和它互动

| 动作 | 结果 |
|---|---|
| 戳它一下 | 挠挠头 + 眼睛眨一下，冒一句吐槽（「戳我干嘛」「去倒杯水吧」） |
| 3.5 秒内连戳三次 | 往反方向躲开 78 像素，摆出防御姿态，说「躲开你」 |
| 鼠标在屏幕上移动 | 它会转头跟着看（只在坐姿时生效，站起来做动作时不看） |
| 按住卡片拖动 | 可以拖到任意位置。松手 1 秒后自动行为恢复 |

## 设置项

![设置界面](docs/images/settings.png)

| 分组 | 项目 | 默认值 | 说明 |
|---|---|---|---|
| 提醒节奏 | 软提醒 | 60 分钟 | 到这个时长弹出提醒 |
| | 强提醒 | 90 分钟 | 到这个时长仍未响应则升级 |
| | 每日上限 | 8 次 | 一天最多提醒几次，超过后状态栏显示「已满」 |
| | 稍后提醒 | 5 分钟 | 「再等 N 分钟」的 N |
| 免打扰 | 启用 / 起止时间 | 关闭 / 12:00–13:30 | 支持跨午夜（比如 23:00–08:00） |
| 行为 | 不理会时自动游走 | 开 | 关掉后卡片就固定不动 |
| | 升级为起身动作 | 12 秒 | 弹出多久无响应开始游走 |
| | 静默判定 | 5 分钟 | 多久没碰键鼠算静默（提醒不升级、不追鼠标） |
| | 长静默 | 30 分钟 | 手停这么久可能人不在：**计时照涨**，只是先不弹，手一回来立刻补 |
| | 开会时暂缓提醒 | 开 | 摄像头/麦克风占用时照常计时，但不弹窗，会后补 |
| 启动 | 开机自动启动 | 关 | 写 LaunchAgent，不依赖开发者证书 |

所有设置存在 `UserDefaults`（键名见 `Sources/Prefs.swift`），计时快照存在 `~/Library/Application Support/XieHuiEr/session.json`，删掉它就等于重置今天。

## 形象与解锁

![四个形象](docs/images/mascots.png)

| 形象 | 代号 | 解锁条件 |
|---|---|---|
| 羊毛毡小熊 | `c` | 默认拥有 |
| 毛绒橘猫 | `a` | 连续坚持 5 天 |
| 圆胖猫头鹰 | `d` | 连续坚持 10 天 |
| 水彩水獭 | `b` | 连续坚持 15 天 |
| 老友模式（不是形象，是语气） | — | 连续坚持 30 天 |

解锁的瞬间会自动换上，并在菜单栏播报一句。**不想等就直接用菜单里的「解锁全部形象（调试）」**。

形象解锁门槛在 `Sources/Habits.swift` 的 `Unlocks.styles` 里，改数组就行。

### 每个形象的动作语汇不一样

四个形象共用同一套三幕叙事（**困 → 起身卖力 → 瘫回去**），但「卖力」那一拍按解剖学各表：

- 橘猫 / 小熊 / 水獭：站起来伸懒腰 → 捶两拳
- 猫头鹰：站起来展翅伸懒腰 → 振翅两下

猫头鹰是栖鸟，翅膀长在体侧、没有能握的手。硬让它握拳打人既不合解剖，AI 也画不出来（试过两版，出来都是「伸翅膀打招呼」，而且每版都把体型画小一圈）。

![猫头鹰的 13 帧](docs/images/owl-frames.png)

动作库的选择在 `MascotRoutine.variants(for:)`。完整动作循环（含呼吸与停顿时序）见 [`docs/images/owl-loop.mp4`](docs/images/owl-loop.mp4)。

## 隐私与权限

**不需要任何系统权限。** 没有「辅助功能」授权弹窗，没有屏幕录制，没有网络请求。

| 用到的能力 | 实现方式 | 是否需要授权 |
|---|---|---|
| 判断你在不在 | `CGEventSource.secondsSinceLastEventType`（系统公开 API 返回空闲秒数） | 不需要 |
| 判断你真走了 | `CGDisplayIsAsleep`（显示器是否休眠）+ `CGSessionCopyCurrentDictionary`（锁屏/是否在控制台） | 不需要 |
| 判断是否在开会 | `AVCaptureDevice.isInUseByAnotherApplication` + CoreAudio `kAudioDevicePropertyDeviceIsRunningSomewhere`（只查设备是否被占用，不取内容） | 不需要 |
| 鼠标位置 | `NSEvent.mouseLocation`（仅坐标） | 不需要 |
| 开机自启 | 写 `~/Library/LaunchAgents/cn.yuou.xiehuier.plist` | 不需要 |

数据全部留在本地——设置和打卡记录在 `UserDefaults`，计时快照在 `~/Library/Application Support/XieHuiEr/session.json`。没有账号，没有网络请求，不上传任何东西。

## 常见问题

**Q：状态栏一直显示「已满」，不弹了？**
A：今日已达 `dailyCap`（默认 8 次）。菜单里有「重置计时」，或者等跨零点自动归零。

**Q：我手停下来跟人说话、或者读文档时发呆，会计时吗？**
A：会。没碰键鼠不等于离开——人还在座位上就是坐着。停多久都照常累加，只有熄屏/锁屏满 30 秒才算离开。手停超过 5 分钟会进入「静默」，但那只是让提醒变克制（不升级、不追鼠标），不影响计时；超过 30 分钟进入「长静默」，累计照样涨，只是暂时不出卡片，你一动鼠标它就补出来。

**Q：为什么计时突然归零了？**
A：现在只剩两种可能。① 熄屏或锁屏**持续超过 30 秒**——确凿离开，归零并可能计一次休息；② 你点了「我去走走了」「重置计时」，或者「再等 N 分钟」把计时退回去。**手停多久都不会再归零了**——这是 v0.11.0 修掉的老毛病。

**Q：关了 app 再打开，进度还在吗？**
A：在。每 10 秒左右写一次 `~/Library/Application Support/XieHuiEr/session.json`，退出时再写一次。重启后接着显示，不会从 0 开始。
但**只续数字，不补间隙**：如果关掉超过 10 分钟，专注时长从 0 开始（今日累计和今日次数照样保留）。关闭期间你在不在座位上，我们没有证据——把这段时间加进去就是编造，而编造出来的分钟数比归零更糟。

**Q：锁屏两秒、屏幕刚睡就被我碰醒了，进度会没吗？**
A：不会。离开要**持续**够 30 秒才结算，短于这个时长只当没走成，累计原样保留。

**Q：为什么开着会，数字反而一直在涨？**
A：这是有意的。摄像头或麦克风被占用时，你人在座位上坐着，一小时起的会正是最容易久坐的场景——冻住等于把这段整段漏记。所以照常计时，只把弹窗推迟到会后补发。设置里关掉「开会时暂缓提醒」，开会时也会照常弹。

**Q：你是怎么知道我不在开会的？**
A：判断不了。只有一条正向证据：摄像头或麦克风**正被占用**。线下围坐、戴着耳机用手机开会，都测不到。所以「没检测到会议」**不作为**「不在开会」的依据——没有确凿证据时，一律按「你还在座位上」处理（继续计时、照常提醒），而不是反过来。宁可多提醒一次，也不要把久坐时间记丢。

**Q：为什么我出去转了十分钟没打卡，连续天数还是 0？**
A：打卡口径是「**坐够软提醒阈值之后**才离开」。你坐下 10 分钟就走开，不算一次有效休息。这条是有意设计的——否则随手离开一分钟就能刷天数，解锁就失去意义了。

**Q：强提醒会追着我的鼠标跑，怎么让它停下？**
A：点任意一个按钮，或者把它拖到别处（松手后 1 秒会恢复追光标）。设置里关掉「不理会时自动游走」也能彻底退出游走/追光标模式。

**Q：开机自启开了但没生效？**
A：App 位置被移动过的话，LaunchAgent 里的路径会失效——下次启动时会自动重写。另外 `LimitLoadToSessionType: Aqua` 表示只在图形登录会话里启动，通过 SSH 登录不会启动它。

**Q：多显示器上它出现在哪块屏？**
A：鼠标所在的那块屏。定位用的是鼠标位置而不是 `NSScreen.main`（后者会随窗口焦点在双屏间漂移）。

**Q：能出 Windows 版吗？**
A：短期内不会。这个项目的核心是一堆 macOS 专有行为（NSPanel 不抢焦点、`CGEventSource` 空闲时长、`screenSaver` 窗口层级、LaunchAgent），移植到 Windows 基本等于重写。

## 已知限制

- 只在 macOS 13+ 上验证过；Apple Silicon 已验证，Intel 理论可行但没测
- **没有做代码签名和公证**。要分发给别人得自己 `codesign` + `notarytool`，见 [开发指南](docs/DEVELOPMENT.md#8-打包与分发)
- **关机一夜回来从 0 开始**。落盘只续 10 分钟内的快照——久到那个程度，我们真的不知道你中间在不在。这是故意的：归零比编造诚实
- **屏幕设成「永不休眠」时**，熄屏信号永远拿不到。人真走了，累计会一直涨，回来手一动就补弹一次。要走开请手动「暂停 1 小时」
- 素材是「AI 生成 + 脚本对齐」的产物，不是手绘。每个动作只有 1 帧关键姿态，靠时序和停顿做「动起来」的错觉，没有真正的补间
- 喝水提醒还没做（在路线图里）
- 界面只有中文
